Ficha Técnica: Git

Herramienta analizada: Git es un sistema de control de versiones distribuido diseñado para manejar todo tipo de proyectos con rapidez y eficiencia.

[cite: 3]

Para trabajar de manera eficiente con este IDE y el sistema de control, es muy útil utilizar atajos de teclado como Ctrl + S para guardar los cambios rápidamente.

[cite: 3]

Fecha oficial de lanzamiento inicial: 7 de abril de 2005.

[cite: 3]

Para comprobar la versión instalada en el sistema, ejecuta el siguiente comando en tu terminal:

git --version[cite: 3]

En la gestión de versiones también podemos encontrar referencias a subversiones o fórmulas técnicas como la notación v2nd.
